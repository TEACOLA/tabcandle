✓ Zero Data Collection / 完全ローカル動作

tabCandle ("the Extension") does not collect, store, transmit, or share any personal data, sensitive user information, or web browsing history.

1. Information Handling (データの取り扱い)

  • No Data Collection: We do not track, log, or store any personal identifiers, browsing behavior, or page content.
  • Local Processing Only: All operations (monitoring tab creation times, countdowns, and closing unpinned tabs) are executed entirely on your local device.
  • No External Transmission: No data is ever transmitted to external servers, cloud storage, third parties, or analytics platforms.

2. Permissions Used (使用している権限)

tabCandle requests only the minimum necessary permissions to fulfill its single core purpose:

  • tabs: Required to inspect tab open timestamps, check pinned / audio playing status, and close inactive tabs after 240 minutes. Tab URLs or browsing history are never collected or stored.
  • storage: Required solely to save tab timestamps locally across service worker lifecycles. No sensitive information is stored.
  • alarms: Required to periodically run background sweep checks to automatically close expired tabs.

3. Third-Party Services (サードパーティサービス)

The Extension contains no third-party tracking, advertising, analytics SDKs, or external network requests.

4. Changes to This Policy (本ポリシーの変更)

We may update this Privacy Policy from time to time. Any changes will be posted on this page with an updated date.

5. Contact (お問い合わせ)

If you have any questions regarding this Privacy Policy, please open an issue on the official GitHub repository.
